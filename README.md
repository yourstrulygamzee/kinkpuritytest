# Kink Purity Test (a Rice Purity Test parody)
This Kink Purity Test is a ricepuritytest.com parody! If you're unfamiliar with the rice purity test, I recommend you go check it out first, or else my project won't make much sense lol.
The original rice purity test was made for Rice University as a fun way to track 'progress' as students went through
their time at school. This parody is the same idea to the extreme: tracking 'progress' as people go through life and The Scene.

I implore you not to take this project too seriously. Instead, treat it like a lewd lofi art piece to toss on the pile of
other freaky ass sites on the internet.

## How did I make this?
Like any good artist, I steal. Using Chrome's inspect feature, I ripped the files to get started. I removed extra scripts and scaffolding for ads, and removed all links to the real Rice University. I was left with a static HTML start page, and then built out the score page to match. I did my best to keep the aesthetics the same as the original. I used an LLM to clean up any mistakes I made. For the logo, I designed it in Figma, and decided to forgo the background owl tiling bc idgaf.
For the items on the list, I tried to come up with items that were not on the original test while keeping in theme. except of course for the classic last two.
